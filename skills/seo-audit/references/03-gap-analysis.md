# 03 — Competitor Gap Analysis Methodology

Use this when running Mode B: Competitor Comparison.

---

## Information Gain Framework

Google's Information Gain patent (2020) rewards pages that provide additional
new information beyond what existing search results already offer. This is the
core lens for competitor comparison.

### What counts as Information Gain

- **Original data**: surveys, experiments, benchmarks, proprietary stats
- **First-hand experience**: tested it yourself, screenshots of real usage,
  "what actually happened" narratives
- **Deeper coverage**: subtopics the competitor skipped, edge cases addressed,
  more recent data
- **Better structure**: comparison tables, decision flowcharts, interactive
  tools that the competitor presents only as prose
- **Unique perspective**: industry insider viewpoint, contrarian analysis
  backed by evidence, regional/cultural nuance

### What does NOT count as Information Gain

- Rewriting the same facts in different words
- Adding more keywords without new substance
- Longer content that repeats rather than extends
- AI-generated filler that covers topics superficially

## Comparison Process

### Step 1: Parallel Audit

Run the 12-dimension checklist on both pages independently. Record scores.

### Step 2: Content Diff

For Dimension 2 (Content Quality), go deeper:

1. **Topic coverage mapping**: List every subtopic/question each page covers.
   Identify:
   - Topics only the competitor covers (your gaps)
   - Topics only you cover (your advantages)
   - Topics both cover — compare depth and recency

2. **Evidence comparison**: For each shared topic, who provides:
   - More recent data?
   - First-hand experience vs. secondhand summary?
   - Verifiable proof (screenshots, test results) vs. assertions?

3. **Format superiority**: Who uses a more effective format?
   - Comparison tables vs. prose
   - Step-by-step guides vs. vague instructions
   - Visual aids vs. text-only explanations

### Step 3: Intent Match Comparison

Check which page better matches the dominant SERP intent:
- If SERP shows mostly how-to guides and competitor is a how-to while yours
  is a product page, that's a fundamental intent mismatch

### Step 4: Technical Comparison

Compare dimensions 5–7 (Schema, Indexing, Performance):
- Who has richer structured data?
- Who loads faster?
- Who has better mobile experience?

### Step 5: Synthesize Gaps

Rank all identified gaps by:

| Gap Type           | Impact | Effort | Priority |
|--------------------|--------|--------|----------|
| Missing subtopic   | High   | Medium | P1       |
| Weaker evidence    | High   | High   | P1       |
| No schema markup   | Medium | Low    | P2       |
| Slower LCP         | Medium | Medium | P2       |
| Worse readability  | Low    | Low    | P3       |

## Multilingual / Global SEO Comparison

When comparing pages targeting different locales:

### Hreflang Audit
- Does the competitor have proper hreflang while you don't?
- Are there locale variants you're missing?

### Localized Intent
- Search intent can differ by locale. "insurance" in Germany emphasizes
  privacy/data-protection; in the US it emphasizes price comparison.
- Check if the competitor localizes content vs. just translates it.

### Cultural Adaptation
Flag if the competitor adapts:
- CTA style (direct vs. indirect selling)
- Trust signals (different certifications matter in different markets)
- Payment/contact methods (WeChat vs. email vs. phone)
